# # 📊 Sample Superstore Data Analysis

> Turning retail data into actionable business insights using Python and data visualization.

---

## 📖 Project Overview

This project analyzes the **Sample Superstore** dataset to uncover trends in sales, profit, customer segments, shipping, and product performance. The analysis was performed using **Google Colab** with Python data analysis libraries.

---

## 🎯 Objectives

- Explore the dataset
- Clean and preprocess the data
- Analyze sales and profit
- Identify top-performing products and regions
- Visualize business trends
- Generate meaningful insights

---

## 📂 Dataset Details

**Dataset Name:** Sample Superstore

**File Name:** `data.csv`

The dataset contains retail order information from a fictional superstore. It includes customer details, product information, sales, profit, discounts, shipping details, and regional data.

### Dataset Features

- Order ID
- Order Date
- Ship Date
- Ship Mode
- Customer ID
- Customer Name
- Segment
- Country
- City
- State
- Postal Code
- Region
- Product ID
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Discount
- Profit
